# خربوش (Kharboosh) — 8-Bit Egyptian Desktop Pet

تطبيق ويب تفاعلي مستوحى من فكرة شخصية البكسل على سطح المكتب فوق الـ Dock، بنكهة مصرية كاملة باسم **«خربوش»**.

## التشغيل

1. شغّل الملف `start-kharboosh.bat` لفتح السيرفر المحلي على `http://localhost:8765/` وتشغيل المتصفح مباشرة (يفضّل Chrome أو Edge لتشغيل المايك والأوامر الصوتية).
2. أو افتح `index.html` مباشرة في المتصفح.

## المميزات الأساسية

- **شخصية 8-Bit على الـ Dock**: يتحرك خربوش فوق شريط التطبيقات، تقدر تسحبه بالماوس أو تضغط عليه، وتلبّسه طربوش أو سماعة أو كوباية شاي من «المظهر».
- **النظام الصوتي المصري (STT + TTS + SFX)**:
  - تفعيل كلمة النداء: **"يا خربوش"** / **"إيه يا خربش؟"**
  - زر **اتكلم** للتحدث مباشرة بالعامية المصرية (`ar-EG`)
  - نطق الردود بصوت المتصفح + مؤثرات 8-Bit (ضحك، إشعار، لعبة، شخير).
  - إمكانية ربط **Gemini** أو **OpenAI** من نافذة الإعدادات (اختياري).
- **فقاعات الحوار التفاعلية (YES / NO)**: أسئلة خفيفة مثل الأكل والقهوة والمية والتركيز.
- **مؤقت التركيز (Focus Timer / Pomodoro)**: شريط `FOCUS 25:00` مع وضع `Locked In` لمنع المقاطعة والهزار أثناء التركيز + صوت خلفي اختياري.
- **حالة النوم (Sleep Mode)**: سرير أزرق صغير مع `Z Z Z` وردود ساخرة لو حاولت تصحيه.
- **ميني جيم (Catch the Coffee)**: التقط أكواب القهوة الساقطة بالماوس أو الأسهم (مع ثيم إضافي للفطار المصري: شاي وطعمية).
- **الشخصية الثانية (الهودي الوردي)**: إظهار «فلفلة» لتقف وتتحاور مع خربوش على الشاشة.
